# Pathwise AI Demo Script

## Target duration

The recommended recording length is approximately four minutes. The story should follow one learner throughout so that the value of sequencing and adaptation is visible.

| Time | Screen and action | Suggested narration |
|---|---|---|
| 0:00–0:25 | Overview | “Online platforms can show thousands of courses, but they rarely show the right sequence for an individual. Pathwise turns a learner’s goal into an inspectable and adaptive learning path.” |
| 0:25–1:05 | Profile | Enter the data-analyst goal, current level, known Excel skill, twelve-week target, six weekly hours, and hands-on/project preferences. Use the AI-assisted profile extraction button, then point out that every field remains editable. |
| 1:05–1:50 | Generate roadmap | Generate the roadmap. Explain that Pathwise compares the learner’s known skills with target capabilities and ranks catalog items deterministically by skill coverage, level, time, format, and prerequisites. |
| 1:50–2:35 | My Path | Open two cards. Read “Why this now” and show prerequisite order, milestones, course metadata, and the project evidence step. Emphasize that course facts originate in the normalized 80-course catalog. |
| 2:35–3:10 | Adaptation | Complete the first item, then select “Too difficult” or “Prefer hands-on” on another item. Point to the visible explanation showing why later steps were reordered. |
| 3:10–3:35 | Skills | Show the skill-gap map and path-progress ring. Explain that Pathwise treats completion as evidence and does not claim proficiency automatically. |
| 3:35–4:05 | Assistant | Ask why the next item is scheduled. Explain that the assistant is grounded in current catalog facts and path context and has a deterministic fallback. |
| 4:05–4:20 | Close | “Pathwise provides a credible route from intention to applied proof: personalized, explainable, prerequisite-aware, and adaptive.” |

## Recording notes

Use 1440×900 or 1280×720 resolution, enlarge browser text to 100%, and ensure no personal credentials or source-file paths are visible. Start with the overview and maintain the same learner profile throughout. If an LLM response takes longer than desired, the application’s fallback still demonstrates the complete product flow.
